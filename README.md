# Amber Morrey Studio

Editorial one-page-plus site for Amber Morrey — personal shopper, Melbourne.
Static HTML/CSS/JS, no build step.

## Pages
- `index.html` — home
- `services.html` — services & Style Goal Quiz
- `journal.html` — the style journal
- `about.html` — about
- `contact.html` — contact / enquiry form

Shared `styles.css` and `app.js` power every page.

## Local preview
Open `index.html` in a browser, or run `npx serve` in this folder.
